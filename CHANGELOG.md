# Changelog

## 0.1.0 (2026-08-06)

- Initial release of **LAF Agent**: native macOS desktop client powered by [Prime Agent](https://github.com/PrimeIntellect-ai/prime-agent).
- Backend fully re-platformed from the acquired legacy codebase onto prime-agent's RPC protocol (JSONL over stdio).
- Per-tool permission approval via a bundled prime-agent gate extension.
- Legacy remote endpoints (auto-update feed, telemetry, marketing site) removed.
