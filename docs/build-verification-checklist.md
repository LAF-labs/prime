## 0. 가장 먼저 볼 것 — 게이트가 로드됐는가

에이전트가 **코드/파이썬 이야기를 꺼내면 게이트가 안 붙은 것**이다. 확인 방법:

아무 스레드나 열고 "안녕"이라고 보낸다.

- ✅ 평범한 대화체로 답한다
- ❌ 코드를 쓰겠다거나, 파이썬 패키지를 설치하겠다거나, `uv pip install`을 언급한다

후자면 하네스의 기본 RLM 프롬프트가 살아있는 것이고, 아래 항목 전부가 무의미하다.
(기본 프롬프트가 아직 파이썬 커널을 광고하는 것은 확인됨 — 하네스 쪽 문구라 우리가
지우지 않았고, 게이트가 이를 통째로 교체한다.)

## 1. 스킬 (allowlist + 프롬프트 등재 + 본문 열기)

**왜**: 스킬 3종은 어제 처음 만들어졌고, Rust가 `--skill` 경로와 `LAF_SKILLS_DIR`을
번들 안 경로로 넘겨야 동작한다. 그 경로 해석은 빌드해야만 검증된다.

1. 명령 팔레트(`/`)를 연다.
   - ✅ `skill:organize-files`, `skill:find-file`, `skill:summarize-docs` 세 개만 보인다
   - ❌ `skill:ui`, `skill:open-knowledge-*`가 보이면 allowlist가 안 걸린 것
2. "다운로드 폴더 정리해줘"라고 보낸다.
   - ✅ 폴더를 먼저 나열하고, **분류안을 제시한 뒤 멈춘다**(승인 전 이동 없음)
   - ❌ 확인 없이 파일을 옮기면 스킬 본문을 못 읽은 것 → `read_file`이 번들 안
     `laf-skills` 경로를 거부하는지 확인

## 2. 문서 읽기 (PDF · 워드 · 엑셀)

**왜**: 어제 넣은 기능 전체. 라이브러리는 사이드카 `node_modules`에서 지연 로드된다.

각각 준비해 채팅에 드래그하거나 "요약해줘"로 지시:

| 파일 | 기대 |
|---|---|
| PDF (텍스트 있는 것) | 내용 요약. 실패 시 "PDF 리더를 사용할 수 없습니다"면 모듈 해석 실패 |
| `.docx` | 한글 포함 정상 |
| `.xlsx` | 시트명 + 행 내용 |
| `.hwp` | ✅ "한글 파일입니다. PDF나 .docx로 저장하면…" (일반 바이너리 오류 ❌) |
| 스캔된 PDF(글자 없음) | ✅ "스캔이라 글자가 없다"는 안내 |

**긴 문서 하나는 꼭**: 4만 자를 넘기면 요약 끝에 "잘렸다"는 언급이 있어야 한다.
없으면 절반만 읽고 전체인 척한 것 — 가장 위험한 실패다.

2. "내 이름은 ○○야, 기억해"를 몇 번 서로 다른 사실로 반복.
3. ✅ 설정 목록에 그대로 반영되고, 밀려날 때 에이전트가 "가장 오래된 것을 지웠고
   설정에서 볼 수 있다"고 알린다.

## 3-b. 저장소 경고 배너

**왜**: DB 파일을 못 열면 인메모리로 폴백해 앱은 정상 동작하고 종료 시 전부 사라진다.
이제 배너로 알린다.

정상 상태에서는 **아무것도 안 보여야** 한다(그게 기본 확인). 강제로 보려면 DB 파일을
읽기 전용으로 만들고 앱을 재시작:

```bash
chmod 000 ~/Library/Application\ Support/rs.laf-agent/threads.db   # 확인 후 되돌릴 것
```

- ✅ 상단에 빨간 배너: "이 대화는 저장되지 않습니다 —…"
- 확인 뒤 `chmod 644`로 복구
